# GoHard Today photo design handoff

This folder contains the approved design references, the complete Claude implementation prompt, and three standalone photo assets.

## Use on Windows

1. Extract the ZIP and copy this whole folder into C:\dev\GoHardRebuild.
2. Open that repository in Claude Code.
3. Type the following as a direct instruction:

Read gohard-today-photo-design/CLAUDE_PROMPT.md, open its referenced images, and implement the approved Today changes in this repository. Use the included photo assets. These changes and the existing verification/integration workflow are approved; proceed without further check-ins for routine decisions.

The full prompt carries the selected two-column photo layout and the clearer workout exercise preview together. It does not ask Claude to rebuild the app.

## Contents

- CLAUDE_PROMPT.md — complete instructions.
- references/today-workout-refinement.png — primary workout structure.
- references/selected-photo-layout.png — selected overall photo layout.
- references/current-today.jpeg — user-provided current phone screenshot.
- assets/workout-hero.webp — gym photo.
- assets/run-cover.webp — running photo.
- assets/nutrition-cover.webp — decorative food photo.
- ASSETS.md — provenance and crop guidance.

These are design references and image assets. This package does not contain the current Flutter source, a signed IPA, or claims that these new UI changes have already been implemented.
