# Task matrix — the 33 original tasks plus food discovery (N6–N8), fresh implementation

Status vocabulary, used strictly:

- **Verified** — implemented and exercised by the named automated tests and/or the native journey in this rebuild.
- **Partly verified** — implemented; the listed part is verified, the rest is built but not yet exercised.
- **Not implemented** — absent or gated off.

"API" tests run on real disposable PostgreSQL. "Drift" tests use a real on-disk Drift database that is closed and
reopened. "Native" is `integration_test/journey_test.dart` on the Android emulator against the real local API.
Historical results from the original project count for nothing here.
